# AStock 数据字典

## 1. 实时行情 (`astock quote`)

> 数据源: 腾讯财经 API (延迟约15分钟) / 同花顺 Chrome 插件 (实时)

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| price | 现价 | 元 | 当前最新成交价 |
| prev_close | 昨收价 | 元 | 上一交易日收盘价，是计算涨跌的基准 |
| open | 今开 | 元 | 当日开盘第一笔成交价，反映隔夜情绪 |
| high | 最高 | 元 | 当日成交最高价 |
| low | 最低 | 元 | 当日成交最低价 |
| volume | 成交量 | 股 | 当日累计成交股数 |
| turnover | 成交额 | 元 | 当日累计成交金额 |
| bid / bid_vol | 买一价 / 买一量 | 元 / 股 | 盘口最优买价和对应的委托量 |
| ask / ask_vol | 卖一价 / 卖一量 | 元 / 股 | 盘口最优卖价和对应的委托量 |
| change | 涨跌额 | 元 | 现价 - 昨收价 |
| change_pct | 涨跌幅 | % | (现价 - 昨收价) / 昨收价 × 100 |
| high_limit | 涨停价 | 元 | 当日涨停板价格 (主板±10%，创业板/科创板±20%) |
| low_limit | 跌停价 | 元 | 当日跌停板价格 |
| inner_vol | 内盘 | 股 | 主动卖出成交量，卖方以买价成交。内盘大→抛压重 |
| outer_vol | 外盘 | 股 | 主动买入成交量，买方以卖价成交。外盘大→买盘强 |
| stock_status | 交易状态 | - | 连续竞价/闭市/休市等 |

## 2. K线数据 (`astock kline`)

> 数据源: 腾讯财经 API，支持日线/周线/月线/分钟线，可前复权

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| date | 日期 | - | K线对应的交易日 |
| open | 开盘价 | 元 | 该周期第一笔成交价 |
| close | 收盘价 | 元 | 该周期最后一笔成交价，技术分析最核心的价格 |
| high | 最高价 | 元 | 该周期内最高成交价 |
| low | 最低价 | 元 | 该周期内最低成交价 |
| volume | 成交量 | 股 | 该周期内总成交股数 |
| turnover | 成交额 | 元 | 该周期内总成交金额 (腾讯API日线不返回此字段) |

**前复权 (qfq)**: 以最新价格为基准，向历史调整除权除息影响。用于技术分析看真实走势。

## 3. 技术指标 (`astock indicator`)

> 基于K线收盘价序列计算，所有指标均为滞后指标

### MA (移动平均线)

| 指标 | 含义 | 用法 |
|------|------|------|
| MA5 | 5日均线 | 短线趋势，上穿MA10/MA20为金叉(看涨)，下穿为死叉(看跌) |
| MA10 | 10日均线 | 中短线趋势 |
| MA20 | 20日均线 | 月线，中期趋势分界线，站稳MA20视为中期向好 |
| MA60 | 60日均线 | 季线，长期趋势分界线，跌破MA60通常视为转熊 |

### MACD (异同移动平均线)

| 字段 | 含义 | 用法 |
|------|------|------|
| DIF | 快线 (12日EMA - 26日EMA) | DIF>0 多头市场，<0 空头市场 |
| DEA | 慢线 (DIF的9日EMA) | 信号线 |
| 柱状图 | (DIF - DEA) × 2 | 红柱放大=多头增强，绿柱放大=空头增强 |
| 金叉 | DIF 上穿 DEA | 买入信号 |
| 死叉 | DIF 下穿 DEA | 卖出信号 |

### RSI (相对强弱指标)

| 字段 | 含义 | 用法 |
|------|------|------|
| RSI(14) | 14日相对强弱指标 | >70 超买区(可能回调)，<30 超卖区(可能反弹) |

### KDJ (随机指标)

| 字段 | 含义 | 用法 |
|------|------|------|
| K | 快速随机值 | K线上穿D线为金叉(买入) |
| D | 慢速随机值 | K线下穿D线为死叉(卖出) |
| J | 灵敏值 = 3K - 2D | >100 极度超买，<0 极度超卖 |

### BOLL (布林带)

| 字段 | 含义 | 用法 |
|------|------|------|
| 上轨 | MA20 + 2倍标准差 | 价格触及上轨=短期超买 |
| 中轨 | MA20 | 中轨为趋势中值 |
| 下轨 | MA20 - 2倍标准差 | 价格触及下轨=短期超卖 |

## 4. 基本面财务数据 (`astock info`)

> 数据源: 东方财富 datacenter API，返回最近4期报告

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| report_date | 报告期 | - | 如 "2025-12-31" (年报) / "2025-09-30" (三季报) |
| report_type | 报告类型 | - | 年报/半年报/季报 |
| eps | 每股收益 (EPS) | 元 | 净利润 / 总股本。越高越好，是估值(PE)的分母 |
| bvps | 每股净资产 (BVPS) | 元 | 净资产 / 总股本。是估值(PB)的分母 |
| roe | 净资产收益率 | % | 净利润 / 净资产 × 100。巴菲特最看重的指标，>15%优秀 |
| gross_margin | 毛利率 | % | (营收-成本) / 营收 × 100。反映产品定价能力 |
| net_margin | 净利率 | % | 净利润 / 营收 × 100。反映最终盈利能力 |
| revenue_yoy | 营收同比增长 | % | 本期营收 / 去年同期营收 - 1。>0 增长，<0 萎缩 |
| profit_yoy | 净利润同比增长 | % | 本期净利润 / 去年同期净利润 - 1。关注增速变化 |
| debt_ratio | 资产负债率 | % | 总负债 / 总资产 × 100。过高有财务风险，一般<60%较安全 |

## 5. 资金面数据

### 5.1 资金流向 (`astock moneyflow`)

> 数据源: 东方财富 push2his API (当前API连接有问题，可通过Chrome插件获取)

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| main_net_inflow | 主力净流入 | 元 | 大单+特大单净买入。正值=主力在买，负值=主力在卖 |
| small_net_inflow | 小单净流入 | 元 | 散户小额成交净额 |
| medium_net_inflow | 中单净流入 | 元 | 中等单笔成交净额 |
| large_net_inflow | 大单净流入 | 元 | 大单净买入 |

**主力资金**: 通常指大单(>20万)和特大单(>100万)的合计，代表机构/大户资金方向。连续5日/20日主力净流入为重要参考。

### 5.2 实时资金流 (Chrome 插件)

| 字段 | 含义 | 解读 |
|------|------|------|
| main_inflow | 主力流入 | 大户主动买入金额 |
| main_outflow | 主力流出 | 大户主动卖出金额 |
| main_net | 主力净流入 | = main_inflow - main_outflow |
| retail_inflow | 散户流入 | 散户主动买入金额 |
| retail_outflow | 散户流出 | 散户主动卖出金额 |
| retail_net | 散户净流入 | = retail_inflow - retail_outflow |

### 5.3 融资融券 (`astock margin`)

> 数据源: 上交所/深交所 API，返回最新交易日数据

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| fin_balance | 融资余额 | 元 | 投资者借券商钱买股票的未偿还总额。持续增加=看多情绪 |
| fin_buy_amt | 融资买入额 | 元 | 当日融资买入的金额 |
| loan_balance | 融券余额 | 元 | 投资者借券商股票卖出的未偿还市值。增加=看空情绪 |
| loan_sell_vol | 融券卖出量 | 股 | 当日融券卖出的股数 |

**解读**: 融资余额↑ + 融券余额↓ = 市场偏多；反之偏空。融资余额是重要的市场情绪指标。

## 6. 券商研报 (`astock research`)

> 数据源: 东方财富 reportapi，返回最近N篇研报

| 字段 | 含义 | 解读 |
|------|------|------|
| org_name | 机构简称 | 发布研报的券商名称 |
| publish_date | 发布日期 | 研报发布时间 |
| rating | 评级 | 买入 > 增持 > 中性 > 减持 > 卖出 |
| rating_change | 评级变动 | 如 "维持"、"上调"、"下调"、"首次" |
| predict_this_year_eps | 今年EPS预测 | 券商对今年每股收益的预测值 |
| predict_next_year_eps | 明年EPS预测 | 券商对明年每股收益的预测值 |
| title | 报告标题 | 研报的核心观点概括 |
| researcher | 研究员 | 撰写研报的分析师 |

**注意**: 券商研报天然偏乐观（"卖出"评级极少），重点关注评级变动方向和 EPS 预测的变化。

## 7. 高管/机构动态

### 7.1 龙虎榜 (`astock dragon`)

> 数据源: 东方财富 datacenter API

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| close_price | 收盘价 | 元 | 上榜当日收盘价 |
| change_rate | 涨跌幅 | % | 上榜当日涨跌幅 |
| explanation | 上榜原因 | - | 如 "日涨幅偏离值达7%"、"日换手率达20%" |
| buy_amt | 买入额 | 元 | 龙虎榜买方合计买入金额 |
| sell_amt | 卖出额 | 元 | 龙虎榜卖方合计卖出金额 |
| net_buy_amt | 净买入额 | 元 | = buy_amt - sell_amt。正值=买方主导 |
| deal_amt | 成交额 | 元 | 上榜当日总成交额 |

**解读**: 龙虎榜是异动股票的机构/游资动向。关注是否有知名游资席位买入，以及机构买卖方向。

### 7.2 大宗交易 (`astock block`)

> 数据源: 东方财富 datacenter API

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| deal_price | 成交价 | 元 | 大宗交易成交价格 |
| deal_volume | 成交量 | 股 | 大宗交易成交股数 |
| deal_amt | 成交额 | 元 | 大宗交易成交金额 |
| premium_ratio | 溢价率 | % | (成交价 - 当日收盘价) / 收盘价 × 100。溢价>0 买方愿意高价拿货，偏利好 |
| buyer_name | 买方营业部 | - | 买入方券商营业部 |
| seller_name | 卖方营业部 | - | 卖出方券商营业部 |

**解读**: 大宗交易是大额股份转让(单笔≥30万股或≥200万元)。折价成交(溢价率<0)常见，大幅折价可能暗示股东急于减持。

### 7.3 高管增减持 (`astock insider`)

> 数据源: 东方财富 datacenter API

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| holder_name | 变动人 | - | 增减持的高管/大股东名称 |
| direction | 变动方向 | - | 增持(买入) / 减持(卖出) |
| change_num | 变动数量 | 万股 | 增持或减持的股数 |
| change_rate | 变动比例 | % | 本次变动占其原持股的比例 |
| end_date | 变动截止日 | - | 增减持发生的截止日期 |
| after_holder_num | 变动后持股数 | 股 | 增减持后该变动人的总持股 |

**解读**: 高管增持通常视为利好(内部人看好)，减持视为利空。但需结合金额和比例看，小金额减持意义不大。

### 7.4 限售股解禁 (`astock release`)

> 数据源: 东方财富 datacenter API

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| free_date | 解禁日期 | - | 限售股可以上市流通的日期 |
| free_shares | 解禁数量 | 万股 | 本次解禁的股数 |
| free_market_cap | 解禁市值 | 万元 | 解禁股数 × 当前股价 |
| free_type | 解禁类型 | - | 首发原股东限售/定向增发/股权激励等 |

**解读**: 大额解禁(尤其是首发原股东和定增)短期可能形成抛压。关注解禁市值占总市值的比例。

### 7.5 机构持仓 (`astock institution`)

> 数据源: 东方财富 zlsj API，按季报披露

| 字段 | 含义 | 单位 | 解读 |
|------|------|------|------|
| org_type | 机构类型 | - | 基金/QFII(外资)/社保/券商/保险/信托 |
| hold_num | 持有机构家数 | 家 | 有多少家该类型机构持有此股 |
| total_shares | 持股总数 | 股 | 该类型机构合计持股数 |
| hold_value | 持股市值 | 元 | 该类型机构合计持股市值 |
| free_ratio | 占流通股比例 | % | 机构持股 / 流通股 × 100 |
| hold_change | 持仓变动 | - | 加仓/减仓/新进/不变 |
| report_date | 报告期 | - | 季报披露日，如 "2026-03-31" |

**解读**: 机构加仓/新进是正面信号。QFII和社保持仓变化尤其值得关注。注意季报有滞后性。

## 8. 行业数据 (`astock industry`)

> 数据源: 东方财富 push2 API (板块行情) + datacenter API (景气度指标)

### 8.1 行业板块行情

| 字段 | 含义 | 解读 |
|------|------|------|
| code | 板块代码 | 如 "BK1328" |
| name | 板块名称 | 如 "集成电路封测" |
| price | 板块指数 | 行业板块的当前指数点位 |
| change_pct | 涨跌幅% | 板块当日涨跌幅，正值领涨 |
| change_amt | 涨跌额 | 板块指数涨跌绝对值 |

### 8.2 行业景气度指标

| 字段 | 含义 | 解读 |
|------|------|------|
| board_name | 行业名称 | 所属行业板块 |
| indicator_name | 指标名称 | 如 "价格:VA:国产:50万IU/g:25kg" (维生素价格) |
| indicator_value | 指标值 | 当前值 |
| change_rate | 日变化率% | 今日相对昨日的变动 |
| change_rate_1y | 1年变化率% | 同比变动 |

**解读**: 行业景气度指标跟踪上游原材料价格、产量等，可判断行业周期位置。指标上涨=行业景气上行。

## 9. 实时微观数据 (Chrome 插件)

> 以下数据仅通过同花顺 Chrome 插件实时获取，无 CLI 命令

### 9.1 分时成交明细 (TickTrade)

| 字段 | 含义 | 解读 |
|------|------|------|
| trade_time | 成交时间 | 精确到秒 |
| price | 成交价格 | 该笔成交价 |
| volume | 成交量 | 该笔成交股数 |
| direction | 成交方向 | buy(主买)/sell(主卖)/neutral(中性盘) |

### 9.2 盘口5档 (OrderBookSnapshot)

| 字段 | 含义 | 解读 |
|------|------|------|
| bid_prices[5] | 买1-买5价格 | 买方5档委托价，买1最优 |
| bid_volumes[5] | 买1-买5量 | 各档位委托股数 |
| ask_prices[5] | 卖1-卖5价格 | 卖方5档委托价，卖1最优 |
| ask_volumes[5] | 卖1-卖5量 | 各档位委托股数 |

### 9.3 分时线 (TimesharePoint)

| 字段 | 含义 | 解读 |
|------|------|------|
| price | 分钟成交价 | 该分钟最后一笔成交价 |
| volume | 分钟成交量 | 该分钟总成交股数 |
| avg_price | 成交均价 | 当日开盘到该分钟的成交均价 |
| cum_volume | 累计成交量 | 当日开盘到该分钟的总成交股数 |
